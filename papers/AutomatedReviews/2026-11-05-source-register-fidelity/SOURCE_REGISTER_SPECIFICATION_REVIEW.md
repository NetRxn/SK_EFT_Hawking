## Why the design passes

The existing classifier is already the needed authority. The canonical presence check already computes strongest-tier evidence over pdf/tex/abstract.txt/json in the registry-derived canonical phase. Factoring that loop into the same citations module, replacing its original body with the call, and reusing it in the existing acquisition producer is a coherent repair. It avoids a copied classification body, a second strongest scan, another resolver, new gate/check/index/ledger, and a new ADR number. The current header helper is intentionally a different operation: first-hit cross-phase/case discovery favors parseable headers and has different extensions. Replacing it by the strongest helper would suppress real title/venue comparisons. Preserving it unchanged and proving full canonical result equality addresses this seam.

The producer's active checkout already owns its registry, overlay, formulas, bundle drafts and output. Import bootstrapping must add the checkout scripts path as well as the root before canonical imports, because citations imports validate_helpers. The proposed absolute-path unrelated-cwd subprocess and imported __file__ assertions catch the actual context failure and primary editable-install substitution. find_workspace's own module-relative/marker behavior supplies shared resources while the output remains checkout-local.

Declared existing aliases must remain evidence even when their filename differs from the bibkey or their directory differs from the canonical phase. That does not license broadening canonical existence lookup. Comparing their canonical classified tiers against shared canonical-phase discovery is sufficient. A declared old edition can establish held bytes only; it cannot establish edition equivalence, content reading or applicability. The spec correctly leaves those debts visible. Null/stale declarations, empty files and directories cannot hide stronger valid canonical evidence or manufacture full holdings.

Actual inprep is the relevant identity, and explicit contradictory overlay identity must refuse regeneration. Consistent external route, bearing and notes survive. No blank DOI/notes/citation_class or prefix becomes an internal identity or new acquisition exemption. Keeping the bearing floor and advisory acquisition semantics preserves ADR014 rather than turning this into a new acquisition service.

The registration probe really exited1; verify_scope's generic src/scripts mapping already supplies its code-change plan, so the literal-name miss does not justify adding a redundant registration string. The optional sync edge is not owed by this explicit producer. Preserve the raw failure and explanation, and rerun before shipping as planned.
