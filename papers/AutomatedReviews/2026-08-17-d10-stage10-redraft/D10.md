- **severity:** MAJOR
- **lane:** infrastructure
- **Gate:** NarrativeGrounding (P1)
- **Location:** `scripts/readiness_gates.py:693` (`idx.outgoing(pc['id'], 'SUPPORTS')`);
  `scripts/build_graph.py` (no emitter); `papers/D10/bundle_metadata.json:blocked_p1_gates`
- **Observed:** Gate 7 blocks a paper when an abstract sentence tagged `interesting` has no
  outgoing `SUPPORTS` edge. **No extractor in the tree emits `SUPPORTS`.** The string appears
  in `build_graph.py` zero times. The gate therefore cannot be cleared by grounding a claim —
  only by deleting the triggering sentence from the abstract, since
  `extract_prose_claim_nodes` reads the `\begin{abstract}` block and nothing else.
  This inverts the incentive the gate exists to create: it rewards removing an honest,
  correctly-hedged priority claim and cannot reward backing one.
- **Evidence:** During this redraft the gate went **green** at one point purely because the
  restructure had (for unrelated editorial reasons) left no `first-claim` sentence in the
  abstract — `extract_prose_claim_nodes` returned 7 D10 nodes, all `interesting=False`.
  Nothing had been grounded. Restoring the paper's genuine priority claim to the abstract
  re-blocked it. `scripts/validation/checks/graph_atlas.py:487-505` already records
  `SUPPORTS` in `GATE_EDGE_TYPES_WITHOUT_EMITTERS` as a live defect and names D10 explicitly.
- **Expected:** Either an extractor emits `SUPPORTS` (so a claim can be backed), or Gate 7's
  default for "no SUPPORTS edges exist anywhere in the graph" is `open`/`cannot-measure`
  rather than `blocked` — the same three-state treatment `_eval_narrative_grounding` already
  applies to the zero-ProseClaim case at `readiness_gates.py:712-723`. A gate that
  manufactures a blocker no evidence supports is the mirror of the vacuous pass, and this one
  does it inside the P1 submission set.
- **Fix:** Preferred — give Gate 7 the `cannot-measure` branch when
  `idx.by_type.get('SUPPORTS')` is globally empty, so the verdict reports that nothing was
  measured instead of asserting a failure. Emitting `SUPPORTS` is the larger, better fix and
  belongs with the `PRODUCES`/`CONTRADICTS` siblings in the same register.
- **Verify (executed 2026-08-17, reproduces):**

## 1.2 — 🟠 IMPORTANT — the NEGF spectral relation is verified only for a structureless self-energy; the prior draft implied a general one

- **severity:** IMPORTANT
- **lane:** manuscript (FIXED in this redraft)
- **Gate:** LeanProofSubstance / claim-scope
- **Location:** prior `papers/D10/paper_draft.tex:146-148`; Lean
  `lean/SKEFTHawking/NEGFGreenFunction.lean:66-67, 192-195`
- **Observed:** The superseded draft read "For a Hermitian device Hamiltonian $H$ and lead
  self-energy with broadening $\Gamma$, the retarded Green's function is
  $G^{R}(E) = (E + i\eta - H - \Sigma)^{-1}$", which a reader takes as a general lead
  self-energy. In the Lean, `retardedArg H E η := ((E : ℂ) + Complex.I * (η : ℂ)) • 1 - H`
  — there is no `Σ` argument. The only self-energy in the module is
  `selfEnergy (η : ℝ) := (-Complex.I * (η : ℂ)) • 1`, so `Γ = broadening (selfEnergy η) = 2η·1`,
  a positive scalar multiple of the identity. `spectralFn_eq_gR_broadening_gA` is therefore
  the wide-band, identical-on-every-site limit, not the general NEGF relation.
- **Evidence:** `retardedArg_eq_sub_selfEnergy` proves the Dyson form
  `retardedArg = E•1 - H - selfEnergy η` for exactly that `Σ`; its own docstring says
  "for the `iη` self-energy". `spectralFn_posSemidef` rewrites through
  `spectralFn_eq_two_mul_eta`, confirming `A = 2η·G^R (G^R)ᴴ`.
- **Expected:** A scope statement attached to the equation, since the restriction is
  material to a transport referee.
- **Fix:** **Done in this redraft** — Eq. (13) and the "Scope of Eq. (12)" paragraph in
  Sec. V A now state `Σ(η) = -iη·1`, `Γ = 2η·1`, and that a general Hermitian-decomposable
  `Σ` is not covered. Also recorded in the paper's Limitations.
- **Verify (executed, reproduces):**
  ```
  grep -n "def retardedArg" -A2 lean/SKEFTHawking/NEGFGreenFunction.lean
  # -> signature is (H E η), no Σ parameter
  grep -n "def selfEnergy" -A1 lean/SKEFTHawking/NEGFGreenFunction.lean
  # -> (-Complex.I * η) • 1   (scalar multiple of the identity)
  ```

## 1.4 — 🟠 IMPORTANT — `hohenberg_kohn_variational` returns two of its three conjuncts as hypothesis fields, unchanged

- **severity:** IMPORTANT
- **lane:** lean / manuscript (DISCLOSED in this redraft)
- **Gate:** LeanProofSubstance
- **Location:** `lean/SKEFTHawking/HohenbergKohnVariational.lean:41-64`
- **Observed:** `DensityVariational` carries `ground : Ev n₀ = ⨅ n, Ev n` and
  `nondegen : ∀ n, Ev n = ⨅ m, Ev m → n = n₀` as *fields*. `E₀` is *defined* as `⨅ n, Ev n`.
  The theorem concludes `D.E₀ ≤ D.Ev n ∧ (D.Ev n = D.E₀ ↔ n = D.n₀)` with proof
  `refine ⟨ciInf_le D.bddBelow n, D.nondegen n, ?_⟩ ; rintro rfl ; exact D.ground`.
  The forward implication **is** `nondegen` applied; the reverse **is** `ground`. Only the
  bound is derived, by one Mathlib lemma. This is not a `PlaceholderMarker` (the body is not
  `rfl`), so Gate 5 does not see it, but it is the same defect class: a cited theorem whose
  conclusion is its own hypothesis.

  `F₁ < F₂ → F₂ < F₁ → False`.
- **Expected:** Gate 5's `PlaceholderMarker` set keys on trivial proof *bodies*. A conclusion
  that is a projection of a hypothesis argument escapes it. This is a detector gap worth
  closing alongside 1.1.
- **Fix:** Manuscript side is **done** — Sec. IV of the redraft states conjunct by conjunct
  which are fields returned unchanged, and the abstract withdraws the DFT novelty claim
  entirely. Lean side: a `hohenberg_kohn_variational` derived from an operator rather than a
  structure would be the real fix and is the open row in the paper's Table I.
- **Verify (executed, reproduces):**
