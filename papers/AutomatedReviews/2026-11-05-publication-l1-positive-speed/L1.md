- **Location:** `src/core/formulas.py::c_GW_from_chi_vest`, `src/gravitational_waves/c_GW_computation.py::c_GW_grid`, `tests/test_gravitational_waves.py`
- **Observed:** The implementation evaluates `1 + (chi - 1)` before taking the square root. For `chi=1e-18`, the scalar result with unit light speed is zero instead of `1e-9`. The expression dates to the original April introduction; its critical susceptibility is fixed at one.

Preserve the scalar API and nonfinite behavior of direct real square-root evaluation. This repairs computation of the assumed law; it does not derive the physical susceptibility or mode.

[Independent control](INDEPENDENT_CONTROL.json) preserves exact-ratio, high-precision scalar and public-grid checks, including tiny positive, typed and nonfinite inputs.
- **Fix:** Promote susceptibility and light-speed scalar arithmetic with `np.result_type`, evaluate the square root of susceptibility directly, and return a float. Add exact-reference scalar and public-grid regressions with an explicit output-ulp budget.
