## 6. Standing harness rules (learned the hard way; see README §4b)

- Scope every mutation to the target function's AST span; restore by writing back saved bytes,
  **never `git checkout`**, and **delete the cached `.pyc`** — a same-length mutation restored inside
  one second survives a source restore and later runs import mutated bytecode from a clean tree.
- Never take a "before" characterization in a `git worktree` — it lacks gitignored artifacts, so
  every Lean check takes its absent branch and the diff is noise. Revert only the changed source
  files in place.
- A MISSED mutation is a finding, never a formality: it means the guard is inert, the test is
  vacuous, or the line should not be counted as verified.
