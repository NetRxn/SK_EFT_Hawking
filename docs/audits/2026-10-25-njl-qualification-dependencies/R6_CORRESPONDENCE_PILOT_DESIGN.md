# R6 prose statement correspondence pilot

Decision authority is [ADR-004 R6](../../adrs/ADR-004-substrate-integrity-gates.md), which assigns structural correspondence to the existing declaration-index and claims-review machinery. This pilot implements neither a third name resolver nor a general TeX-to-Lean translator. The historical critical finding and [current reproduction](NJL_R6_REPRODUCTION_20261103.md) remain open.

| Ambiguous or unrelated display | Multiple possible attributions, a name mentioned as background, an unsupported TeX binder or a declaration missing an elaborated type. | Require explicit attribution or report unmeasured for structural review. Never infer an attribution by proximity alone. |

1. **Attribution.** Reuse the current prose candidate scanner and canonical typed declaration resolution. Delimit a complete display and consume a direct attribution (historical D3's explicit “and is theorem” is the seed); otherwise use an explicit anchor through the existing claim backing record. Bind any manual correspondence to the exact display and elaborated statement so either edit invalidates it. The independent design review must check the actual backing-record fields before choosing this second route.
2. **Discriminator.** Extract the bound variable and domain shape from the display. On the Lean side identify the matching local binder and premise scope before checking an interval membership or an endpoint disjunction. Do not count an `Or` in the conclusion or a separate hypothesis as an endpoint domain. Record unsupported structures for Class SC review.
3. **Non-vacuity.** On the current D3 draft seed the historical interval display with the exact existing endpoint theorem, then run the public readiness path. Check the positive endpoint control, an ordinary unrelated equation and a display with ambiguous reference. Preserve resolver behavior for modules, aliases and incidental theorem tokens. Recheck any registered measurement denominator rather than allowing an empty population to pass.
4. **Delivery.** Pilot the classifier on the D3 controls, then inventory actual direct attributions on all 21 drafts before selecting coverage policy. Obtain adversarial spec review before production code. Wire the deterministic leg into existing validation and SC into claims review according to ADR-004. Independently verify the seeded fault and the finding's declared Verify before canonical closure.

The literal historical attribution shape (equation or align ending, optional noindent, then “and is theorem” followed by a texttt declaration) matched once in the historical D3 draft and zero times in the 21 current top-level drafts. This is a seam control, so a detector keyed solely to that phrasing would run over an empty live population. The proposed typed backing-record route must establish a nonempty measured population before gate wiring.

A scratch probe of the D3 negative case reused the existing elaborated-type token and arrow splitters in `lean_statements.py`. The current exact declaration splits into the nonzero-speed premise, a susceptibility binder with a two-equality disjunction, and a negated conclusion. Both disjuncts bind that same susceptibility. The Lean definitions give endpoints 1/10 and 10, so the displayed interval's midpoint 5.05 is a concrete scope witness. This isolates domain mismatch from the conclusion's operators and gives a regression control for the reusable parser seam.
